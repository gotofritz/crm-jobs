# Architecture & Setup

## Development

### Initial Setup

After installation (see [README](../README.md)), create a superuser:

```bash
uv run python manage.py createsuperuser
```

This creates a login for Django admin at `/admin/`.

### Database

Development uses SQLite at `./db.sqlite3` (gitignored).
